※ 불량 데이터: 공정불량2 시트 / 생산수량: 생산수량 시트. 불량률은 동일 기간 전체 생산수량을 분모로 계산한 지표입니다. 모델·공정·불량명 필터를 적용한 불량률은 선택 불량수량을 기간 전체 생산량으로 나눈 값이며, 모델별 실제 불량률을 의미하지 않습니다. 두 시트 간 품목코드 체계가 달라 모델별 생산량 매칭은 수행하지 않았습니다. 날짜는 발생일자, 생산량은 계획일을 기준으로 집계합니다. 기본 데이터는 HTML에 내장되어 있습니다. 같은 웹사이트의 dashboard-data.json이 존재하면 자동으로 최신 데이터를 읽습니다. 엑셀 파일을 선택하면 현재 브라우저에서 데이터가 교체되며 서버에 자동 저장되지는 않습니다.
